📚 Sistema de Manuales de Usuario - ProsperPOS

✅ Sistema Implementado Correctamente

El sistema de manuales ha sido configurado y está listo para usar.

📋 Archivos PDF Requeridos

Para que el sistema funcione completamente, necesitas crear y colocar los siguientes archivos PDF en esta carpeta:

  • manual-administrador.pdf - Para usuarios Super Admin y Admin
  • manual-vendedor.pdf - Para usuarios Vendedor (cashier)
  • manual-bodega.pdf - Para usuarios de Bodega (warehouse)
  • manual-tienda-online-cliente.pdf - Guía para clientes de la tienda
  • manual-tienda-online-gestion.pdf - Guía de gestión de tienda online
⚠️ IMPORTANTE:
  • Los nombres de los archivos deben ser exactamente como se muestran arriba
  • Todo en minúsculas
  • Con guiones (-) en lugar de espacios
  • Extensión .pdf

🎯 Cómo Funciona

Sección "Ayuda" (Menú Principal)

  • Administradores verán: "Manual de Usuario - Administrador"
  • Vendedores verán: "Manual de Usuario - Vendedor"
  • Personal de Bodega verá: "Manual de Usuario - Personal de Bodega"

Módulo "Tienda en Línea"

Todos los usuarios que accedan al módulo de Tienda en Línea verán:

  • "Manual de Tienda en Línea (Vista Cliente)"
  • "Manual de Gestión de Tienda en Línea"

Estos manuales aparecen en la sección "Acciones", debajo de "Ver Tienda Online".

🔍 Cómo Probar

  1. Coloca los archivos PDF en esta carpeta (template/public/manuales/)
  2. Inicia sesión con un usuario de prueba (admin, vendedor, almacenista, etc.)
  3. Ve a la sección "Ayuda" en el menú lateral
  4. Verifica que solo aparece el manual correspondiente a tu rol
  5. Haz clic en el manual para descargarlo
  6. Para tienda online: Ve al módulo "Tienda en Línea" y verifica los manuales en "Acciones"

👥 Usuarios de Prueba

Puedes probar con estos usuarios del sistema:

  • admin - Ver manual de administrador
  • vendedor - Ver manual de vendedor
  • almacenista - Ver manual de bodega

🛠️ Solución de Problemas

El manual no se descarga

  • Verifica que el archivo PDF existe en esta carpeta
  • Revisa que el nombre del archivo sea exacto
  • Abre la consola del navegador (F12) para ver errores

El manual no aparece en el menú

  • Verifica que el usuario tiene el rol correcto
  • Cierra sesión y vuelve a iniciar para refrescar los permisos
  • Revisa la consola del navegador por errores
