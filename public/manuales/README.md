# Manuales de Usuario - ProsperPOS

Esta carpeta contiene los manuales de usuario en formato PDF para cada rol del sistema.

## Instrucciones

Coloca los siguientes archivos PDF en esta carpeta:

1. **manual-administrador.pdf** - Manual para usuarios Administradores
2. **manual-vendedor.pdf** - Manual para usuarios Vendedores
3. **manual-bodega.pdf** - Manual para Personal de Bodega
4. **manual-tienda-online-cliente.pdf** - Manual de Tienda Online (Vista Cliente)
5. **manual-tienda-online-gestion.pdf** - Manual de Gestión de Tienda Online

## Notas

- Los archivos deben tener exactamente estos nombres
- El sistema descargará automáticamente el manual correspondiente según el rol del usuario
- Los manuales de tienda online aparecerán en el módulo de Tienda en Línea
